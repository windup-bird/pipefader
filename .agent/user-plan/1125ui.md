## browser

### stacked

点击browser后deckinfo会移动，应该复用当前的定义，只变纵向高度不该内部控件位置/缩放, 当前缩放都改了

### full样式

现在应该是三栏: library, list+tracks, right(nothing now) (我忘了定义，你可以告诉我)

每栏对应pane

```text
fresh-icon | 'Library' | left-toggle | <Library-name> | ... |(右对齐) status | <icon> 'analyse' | search | right-toggle
		library        |			lists and tracks													 |
```

点击toggle展开/收起对应的栏和pane并且有平移动画（full）

analyse点击后分析当前list(tracks栏里)的全部歌曲

search点击后铺满横向宽度

```
<library> <down-icon> | <list> <down-icon> | <search-icon> | bar ... | (右对齐) <close-icon>
```

左边两个按钮相当于filter，限制搜索范围

### 其他布局的browser
