## 对比其他混音软件

### Mixxx

更轻量，更友好的界面，可视化Midi映射编辑，支持实时Stem分离。

### Rekordbox

更低占用，更快启动，支持任意设备和自定义映射，无订阅制和付费。

### Djay

在Windows更好的性能和更低的占用，在Android也有全量的功能，全平台统一不阉割。

### Serato

可读取onelibrary，免费解锁Midi自定义和Stem分离。

### EngineOS

代码全开源，可自定义部署到任意开发版用于一体机系统；

多后端的实时Stem分离，且不同于Prime4 G2，我们的分离使用**分段计算、流式装载**，只要分离时间跑赢播放时间就可实现实时分离。
